# Project governance

Chat Unleashed is currently maintainer-led. The repository owner, [PotterSkxawng](https://github.com/PotterSkxawng), makes final decisions on scope, release timing, merges, and repository policy after considering contributor feedback.

## Proposals and decisions

Use GitHub issues for bugs and feature proposals. Discuss major architecture or permission changes before opening a large pull request.

Maintainer decisions weigh user safety, privacy, reliability, macOS compatibility, maintainability, and test evidence. Maintainers may request changes, defer a proposal, or decline it. Opening an issue or pull request does not authorize deployment.

Git history and applicable license notices preserve contribution credit. The project does not currently use formal voting, guaranteed review windows, or automatic commit access.

## Releases

A commit landing on `main` is not automatically a stable release. Published release notes and tags should state the tested functionality and known limitations.

Do not change a user's installation or restart a live tunnel merely because a commit has landed.

## Security and community standards

Use [SECURITY.md](SECURITY.md) for confidential vulnerability reporting, [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for participation standards, and [CONTRIBUTING.md](CONTRIBUTING.md) for the review and testing process.

Governance may change as the maintainer and contributor group changes.
