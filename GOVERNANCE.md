# Project governance

Chat Unleashed is currently a maintainer-led project. The repository owner, [PotterSkxawng](https://github.com/PotterSkxawng), makes final decisions about scope, release timing, merges and repository policy after considering contributor feedback.

## Proposals and decisions

- Use GitHub issues to describe bugs and proposed features. For major architecture or permission changes, discuss the problem and tradeoffs before opening a large pull request.
- Decisions weigh user safety, privacy, reliability, macOS compatibility, maintainability and test evidence.
- Maintainers review pull requests when available and may request changes, defer a proposal or decline a change. A proposal is not an approval to deploy it.
- Contributions remain credited through Git history and applicable license notices. There is no formal voting, guaranteed review window or automatic commit access.

## Releases and changes

Changes to `main` are not automatically declared stable releases. Release notes and tags, when published, should identify tested functionality and known limitations. Do not change user installations or restart live tunnels merely because a commit has landed.

## Security and community standards

See [SECURITY.md](SECURITY.md) for confidential vulnerability reporting, [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for participation standards, and [CONTRIBUTING.md](CONTRIBUTING.md) for the review and testing process. Governance can evolve as maintainers and contributors become available.
